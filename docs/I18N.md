# i18n

**Scope:** English complete. Marathi and Hindi complete on: sign-in, lead form, bill-review messages, lead result, quote story + PDF headline sections, status page, stage names, message templates. Everything else falls back to English (documented, deliberate).

**Rules:** strings live in typed files `lib/i18n/{en,mr,hi}.ts`; `en.ts` defines the key type, others must satisfy it (compile error on missing key where in scope). No hard-coded text in components. Key naming: `screen.element.purpose` (e.g. `lead.step1.title`). Devanagari font loaded only when locale needs it. `<html lang>` follows locale. Numbers via `Intl` `en-IN`; Devanagari digits accepted on input (Postel).
