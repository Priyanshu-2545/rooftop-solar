Before UI work read `docs/DESIGN_SYSTEM.md`. Use tokens only (no raw hex in components). Saffron only on the primary action and the sun of the arc. Sun-arc appears only in form progress, stage timeline and quote hero. Buttons ≥48px, labels above inputs, 6px radius, no gradients/glass/shadows. Run the anti-slop checklist before committing UI changes. No hard-coded strings (see i18n skill).
